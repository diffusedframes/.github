# Security policy

Please report suspected vulnerabilities privately in the affected repository. Open its **Security** tab and choose **Report a vulnerability**.

For USD Pose Bridge, use [private vulnerability reporting](https://github.com/diffusedframes/comfyui-usd-pose-bridge/security/advisories/new).

Include the affected pack and version, reproduction steps, likely impact, and any proposed fix. Share the smallest example needed, and avoid including credentials or unrelated private files.

If private reporting is unavailable, open an issue asking maintainers to enable it without posting vulnerability details or an exploit. Ordinary bugs that have no security impact can use the public bug report form.

Security fixes are made through the relevant pack's releases. Use its latest release and check its release notes for fixes. Older versions do not have a guaranteed security maintenance period, and response times depend on maintainer availability.
