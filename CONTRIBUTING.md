# Contributing to DiffusedFrames

Please contribute in the repository for the affected pack. Check its README and any repository-specific guidance first.

## Report a problem

Search existing issues, then use the bug report form. Include the pack version, ComfyUI version and installation type, operating system, relevant logs, and clear reproduction steps. A small workflow or sample scene is useful when you have permission to share it. Remove credentials, private paths, and personal or proprietary data before uploading files.

For feature requests, describe the creative workflow and the problem you want to solve. Examples of the desired input and output help make proposals concrete.

Report vulnerabilities through the process in [SECURITY.md](SECURITY.md).

## Send a pull request

Keep the change focused and explain what users will experience differently. For a larger feature or new dependency, open an issue first so its scope can be discussed.

Follow the pack's existing style and installation instructions. Run its relevant checks, describe what you verified, and update examples or documentation when behavior changes. Add a regression test when it meaningfully protects a bug fix or new behavior. Do not commit generated caches, local environments, credentials, or files you cannot redistribute.

Use a clear title and include screenshots or sample outputs when they help review a visual change. You do not need to promise a release date or a support response time; contributions are reviewed as maintainer time allows.

Keep discussions respectful, specific, and focused on the work.
