# Diffused Frames

**From Noise to Production.**

Diffused Frames explores AI video, VFX and filmmaking through weekly episodes, source-linked news, practical workflows, creative tools and shared tests.

This GitHub organization brings together our tools, test packs, workflow examples and supporting resources. Visit the website for the episodes, reporting and guides that connect them.

[Website](https://www.diffusedframes.com/) · [YouTube](https://www.youtube.com/@diffusedframes) · [Instagram](https://www.instagram.com/diffused.frames/) · [Repositories](https://github.com/orgs/diffusedframes/repositories)

## Diffusion Weekly Pills

Your weekly diffusion pill: developments in AI video, VFX and filmmaking, with a practical production perspective. Explore the tools, creative possibilities and questions behind the headlines, with links to the original sources and further coverage.

## Community test packs

Shared inputs, exact prompts, versioned workflows and timing protocols to help compare results across hardware and setups. Download a pack, run it when your machine is available, and contribute the output, settings and time it took.

The first pack is **LTX 2.5 image-to-video: a café moment**. It is a pilot; a clean reference baseline and reviewed performance results are still pending. Failed runs and compatibility reports are useful too.

[Explore the test packs](https://github.com/diffusedframes/test-packs) · [Community tests on the website](https://www.diffusedframes.com/tests/) · [Contribute a result](https://github.com/diffusedframes/test-packs/issues/new?template=test-result.yml)

GitHub submissions and attachments are public immediately. Website features are selected after review and follow the contributor's publication choice.

## Creative tools

Tools connecting 3D scenes, animation and generative workflows, with examples and documentation to help you get started.

### [DiffusedFrames USD Pose Bridge](https://github.com/diffusedframes/comfyui-usd-pose-bridge)

Bring OpenUSD skeletons, animation, and cameras into OpenPose workflows in ComfyUI. Render pose images, work with multiple characters, adjust joint mapping, and exchange keypoint JSON.

[![USD Pose Bridge animation preview](https://raw.githubusercontent.com/diffusedframes/comfyui-usd-pose-bridge/main/examples/demo_animation.gif)](https://github.com/diffusedframes/comfyui-usd-pose-bridge)

**Development preview.** See the pack's README for installation instructions, requirements, examples and current validation status.

[Explore the pack](https://github.com/diffusedframes/comfyui-usd-pose-bridge) · [Report an issue](https://github.com/diffusedframes/comfyui-usd-pose-bridge/issues)
