# DiffusedFrames

Creative tools connecting 3D scenes, animation, and generative workflows.

We build ComfyUI custom nodes that help artists carry useful scene data into image and video workflows. Each pack has its own installation, examples, dependencies, and releases.

## First pack

### [DiffusedFrames USD Pose Bridge](https://github.com/diffusedframes/comfyui-usd-pose-bridge)

Bring OpenUSD skeletons, animation, and cameras into OpenPose workflows in ComfyUI. Render pose images, work with multiple characters, adjust joint mapping, and exchange keypoint JSON.

[![USD Pose Bridge animation preview](https://raw.githubusercontent.com/diffusedframes/comfyui-usd-pose-bridge/main/examples/demo_animation.gif)](https://github.com/diffusedframes/comfyui-usd-pose-bridge)

**Development preview.** ComfyUI Manager publication is pending. See the pack's README for installation instructions, requirements, examples, and current validation status.
