# DiffusedFrames community files

This repository holds the [DiffusedFrames organization profile](profile/README.md) and shared contribution, support, security, issue, and pull request guidance.

GitHub applies these defaults to DiffusedFrames repositories that do not define their own files of the same type. A pack can supply its own guidance when it needs something more specific. Issue forms and their configuration live in `.github/ISSUE_TEMPLATE`; a pack that defines its own issue templates uses those instead of the shared forms.

The organization profile is maintained in `profile/README.md`. Keep pack links and publication status current when adding or releasing a project.

Each independently installable node pack belongs in its own repository, with its own requirements, examples, tests, version, and license. The license in this repository applies to these community files; GitHub does not supply it as a default license for other repositories.

See [GitHub's default community file documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for the inheritance rules.
