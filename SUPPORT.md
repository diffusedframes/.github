# Getting help

Start with the affected pack's README, installation instructions, and example workflows. Each pack documents its own requirements and current limitations.

For bugs and feature requests, search the pack's existing issues and then open an issue in that repository. Include your pack version, ComfyUI version and installation type, operating system, and enough detail to reproduce the problem. Use the bug report form for installation failures too.

For [DiffusedFrames USD Pose Bridge](https://github.com/diffusedframes/comfyui-usd-pose-bridge), use its [issue tracker](https://github.com/diffusedframes/comfyui-usd-pose-bridge/issues).

Keep pack support requests in the pack's repository. This `.github` repository is for shared organization documentation and templates.

Remove credentials and private material from logs and workflows before sharing. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

Response and release times depend on maintainer availability.
